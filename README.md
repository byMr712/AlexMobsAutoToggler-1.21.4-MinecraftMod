# Vanilla Recipe Isolator (Minecraft 1.21.4 Fabric)

Универсальный клиентский мод для **Minecraft 1.21.4 (Fabric)**, обеспечивающий чистую совместимость и изоляцию модов при подключении к любым ванильным и межверсионным серверам (включая ViaFabricPlus).

---

## Что решает Vanilla Recipe Isolator

Когда на клиенте установлены контент-моды (например, `tide`, `regs-more-foods`, `StrawBed`, `TotemCraft`, `Alex's Mobs` и др.), они регистрируют свои блоки, предметы и поля сущностей в общие реестры игры. При подключении к ванильным серверам это приводит к серьезным багам:

1. **Сдвиг ID блоков и палитры чанков**:
   - Новые блоки модов смещают глобальную таблицу `Block.STATE_IDS`. На ванильных серверах (или через ViaFabricPlus) блоки начинают отображаться неверно (например, сахарный тростник выглядит как цветущий аметист, сундуки превращаются в мод-блоки и т.д.).
   - **Vanilla Recipe Isolator** перехватывает палитры чанков и обращение к `Block.STATE_IDS`, подставляя эталонную ванильную карту ID 1.21.4.

2. **Сдвиг ID предметов (`Item.byRawId`)**:
   - Гарантирует, что сетевые пакеты предметов всегда используют эталонные ванильные ID предметов на мультиплеере.

3. **Сдвиг метаданных сущностей (`DataTracker`)**:
   - Моды на мобов (такие как `Alex's Mobs`) добавляют лишние сетевые поля в `LivingEntity`, что вызывает `IllegalStateException: Invalid entity data item type`.
   - **Vanilla Recipe Isolator** динамически выравнивает индексы полей и блокирует несовместимые сетевые обновления данных.

---

## Где и как это работает

| Режим игры | Поведение |
|---|---|
| **Ванильный сервер / ViaFabricPlus (26.x, 1.21.x и др.)** | Изоляция **активна**: используются чистые ванильные таблицы ID, исключены любые визуальные и сетевые конфликты |
| **Мультиплеерный сервер с установленными модами** | Изоляция синхронизируется через Fabric API |
| **Одиночная игра** | Изоляция **выключена**: все блоки, предметы и мобы из всех ваших модов работают на 100% |

Всё происходит полностью автоматически при подключении к серверу и не требует ручных настроек.

## Сборка

```bash
gradlew build
```

Готовый файл: `build/libs/VanillaRecipeIsolator-1.21.4-byMr712.jar`.

## Установка

1. Установите **Fabric Loader** (0.16.0+) и **Fabric API** для 1.21.4.
2. Поместите `VanillaRecipeIsolator-1.21.4-byMr712.jar` в папку `mods/`.
3. Запустите игру.
