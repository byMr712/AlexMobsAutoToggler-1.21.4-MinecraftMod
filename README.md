# AlexMobs AutoToggler (Minecraft 1.21.4 Fabric)

Клиентский мод для **Minecraft 1.21.4 (Fabric)**, устраняющий ошибку протокола от **Alex's Mobs Continued** при подключении на любой мультиплеерный сервер, если там нет этого мода, а у вас он установлен.

---

## О моде

**Alex's Mobs Continued** (Fabric-версия) добавляет клиенту одно лишнее синхронизируемое поле данных на каждую живую сущность `LivingEntity`. Из-за этого порядковые идентификаторы (id) полей данных "сдвигаются" на единицу относительно ванильного (или иного модифицированного) сервера.

### Симптом: краш при входе на сервер

При входе на ванильный мультиплеерный сервер расхождение id приводит к сбою синхронизации:

```
IllegalStateException: Invalid entity data item type for field 17 ...
old=false(Boolean), new=0(Integer)
```

(поле `fromBucket`/`variant` у рыб: сервер шлёт `Integer`, клиент ждёт `Boolean`).

### Решение

Мод перехватывает клиентскую обработку входящих сетевых обновлений данных (миксин в `DataTracker.writeUpdatedEntries`):

- Поля, тип которых не совпадает на текущей позиции, но совпадает на позиции `id + 1`, получают сдвиг на `+1` (**самокорректирующаяся компенсация** — без жёсткой привязки к конкретному id поля Alex's Mobs Continued);
- Если тип совпадает сразу — сдвиг не применяется;
- Полностью нераспознаваемые записи пропускаются и логируются вместо краша.

### Где это работает

| Ситуация | Поведение |
|---|---|
| Мультиплеерный сервер без alexsmobs | Расстановка полей сервера расходится с клиентской — мод компенсирует сдвиг  |
| Мультиплеерный сервер с alexsmobs | Мод выключен, никак не влияет на поведение **Alex's Mobs Continued** |
| Одиночная игра | Мод выключен, никак не влияет на поведение **Alex's Mobs Continued** |

Компенсация включается автоматически при подключении к любому мультиплеерному серверу и так же автоматически отключается при входе в одиночную игру (не требуется никаких настроек).

## Сборка

```
gradlew build
```

Готовый файл: `build/libs/AlexMobsAutoToggler-1.21.4-byMr712.jar`.

## Установка

1. Установите **Fabric Loader** (0.16.0+) и **Fabric API** для 1.21.4.
2. Скопируйте `AlexMobsAutoToggler-1.21.4-byMr712.jar` в папку `mods/`.
3. Запустите игру (нужна Java 21).

## Технические детали

- Целевые методы (Yarn 1.21.4+build.7): `DataTracker.writeUpdatedEntries` и `DataTracker.copyToFrom`.
- Модификация только клиентская (`environment: client`); миксин не применяется на сервере.
- Совместимость: Fabric Loader 0.16.0+, Minecraft 1.21.4, Java 21, зависимость от Fabric API.
