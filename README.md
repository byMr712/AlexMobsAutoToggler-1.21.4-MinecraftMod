# Vanilla Recipe Isolator (Minecraft 1.21.4 Fabric)

**Vanilla Recipe Isolator** — универсальный клиентский мод для **Minecraft 1.21.4 (Fabric)**, который позволяет играть с установленными контентными модами (на блоки, мобов, еду, оружие, мебель) в одиночной игре и **беспрепятственно заходить на любые внешние серверы (Vanilla, Paper, Purpur, Spigot, Realms и через ViaFabricPlus)** без необходимости отключать моды или менять профили лаунчера.

---

## 🎯 Основная задача мода

Когда в клиенте установлены контентные моды, они регистрируют свои блоки, предметы и сущности в общие реестры игры. При попытке зайти с такой сборкой на обычный сервер (Vanilla, Paper, Spigot и т.д.) или на сервер другой версии через **ViaFabricPlus**, происходят серьёзные сбои:
- Смещаются глобальные ID блоков и предметов (например, ванильный тростник или древесина отображаются как блоки из мода).
- Ломаются пакеты метаданных мобов (`Invalid entity data item type`), вызывая вылеты при встрече ванильных сущностей.
- Засоряется сетевой стек и возникают конфликты рецептов.

**Vanilla Recipe Isolator** автоматически определяет тип подключения и изолирует реестры модов на время сетевой игры, подставляя чистую ванильную структуру данных.

---

## 🛠️ Что делает Vanilla Recipe Isolator

1. **Защита палитры блоков (`Block.STATE_IDS` / сетевые чанки)**:
   - Перехватывает обращения к глобальной палитре состояний блоков и возвращает эталонную ванильную карту 1.21.4. Это предотвращает визуальные подмены блоков в мире при подключении к серверам.
2. **Нормализация ID предметов (`Item.byRawId`)**:
   - Обеспечивает строгую привязку сетевых пакетов предметов к стандартным ванильным идентификаторам.
3. **Защита сетевых метаданных сущностей (`DataTracker`)**:
   - Исправляет конфликты, когда моды (например, моды на новых мобов) добавляют кастомные поля в базовый класс `LivingEntity`, предотвращая краши `IllegalStateException: Invalid entity data item type`.
4. **Бесшовная поддержка ViaFabricPlus**:
   - При использовании **ViaFabricPlus** мод предотвращает путаницу в трансляторах версий (от **1.8** до **1.21.x** и **26.x**), гарантируя, что пакеты перевода версий работают с чистыми ванильными идентификаторами.

## 🎮 Автоматическое распределение режимов

Мод не требует настройки и работает полностью автоматически:

| Режим игры | Поведение |
|---|---|
| **Одиночная игра (Singleplayer)** | Изоляция **выключена**: все ваши блоки, мобы, крафты и предметы из всех модов работают в полном объёме |
| **Ванильный сервер (Vanilla / Paper / Purpur / Spigot / Realms)** | Изоляция **активна**: вы подключаетесь без конфликтов реестров и вылетов |
| **Подключение через ViaFabricPlus (любые версии)** | Изоляция **активна**: трансляторы пакетов работают с эталонными ванильными таблицами |
| **Сервер Fabric с поддержкой ваших модов** | Изоляция синхронизируется через Fabric API |

## ⚠️ Ограничения совместимости

> [!NOTE]
> Мод изолирует стандартные реестры Minecraft (блоки, предметы, метаданные существ). Однако некоторые специфические моды могут содержать глубокие инвазивные миксины в низкоуровневый сетевой стек или нестандартный порядок загрузки классов при инициализации. В таких исключительных случаях может потребоваться точечный патч совместимости.

## 📦 Сборка

```bash
gradlew build
```

Готовый файл: `build/libs/VanillaRecipeIsolator-1.21.4-byMr712.jar`.

## 🚀 Установка

1. Установите **Fabric Loader** (0.16.0+) и **Fabric API** для 1.21.4.
2. Поместите `VanillaRecipeIsolator-1.21.4-byMr712.jar` в папку `mods/`.
3. *(Опционально)* Установите **ViaFabricPlus**, если планируете подключаться к серверам других версий.
4. Запустите игру.
