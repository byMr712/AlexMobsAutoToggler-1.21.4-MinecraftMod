# Modded2Vanilla (Minecraft 1.21.4 Fabric)

**Modded2Vanilla** — универсальный клиентский мод для **Minecraft 1.21.4 (Fabric)**, который позволяет играть со своими любимыми контентными модами (на блоки, мобов, еду, оружие, декорации) в одиночной игре и **беспрепятственно заходить на любые внешние серверы (Vanilla, Paper, Purpur, Spigot, Realms и через ViaFabricPlus)** без необходимости отключать моды или менять профили лаунчера.

---

## 🎯 Основная задача мода

Когда в клиенте установлены контентные моды, они регистрируют свои блоки, предметы и сущности в общие реестры игры. При попытке зайти с такой сборкой на обычный сервер (Vanilla, Paper, Spigot и т.д.) или на сервер другой версии через **ViaFabricPlus**, происходят сетевые конфликты:
- Смещаются глобальные ID блоков и предметов (например, ванильный тростник или древесина отображаются как блоки из мода).
- Ломаются пакеты метаданных мобов (`Invalid entity data item type`), вызывая вылеты при встрече ванильных сущностей.
- Засоряется сетевой стек и возникают конфликты рецептов.

**Modded2Vanilla** автоматически определяет тип подключения:
- При подключении к ванильному/удаленному серверу изолирует лишние данные модов и подставляет эталонную ванильную структуру.
- **Если мод установлен и на клиенте, и на сервере** — его работа **не затрагивается**, пакеты и данные мода синхронизируются штатно!

---

## 🛠️ Что делает Modded2Vanilla

1. **Защита палитры блоков (`Block.STATE_IDS` / сетевые чанки)**:
   - Перехватывает обращения к глобальной палитре состояний блоков и возвращает эталонную ванильную карту 1.21.4. Это предотвращает визуальные подмены блоков в мире при подключении к серверам.
2. **Нормализация ID предметов (`Item.byRawId`)**:
   - Обеспечивает строгую привязку сетевых пакетов предметов к стандартным ванильным идентификаторам.
3. **Умная защита метаданных сущностей (`DataTracker`)**:
   - Автоматически проверяет соответствие типов данных сущности (`entryIdMatches`).
   - Если сервер ванильный, а на клиенте есть мод на мобов (например, Alex's Mobs), смещающий индексы `LivingEntity` — мод безопасно выравнивает индексы.
   - Если сервер тоже имеет этот мод и отправляет кастомные данные — мод пропускает их без изменений.
4. **Бесшовная поддержка ViaFabricPlus**:
   - При использовании **ViaFabricPlus** мод предотвращает путаницу в трансляторах версий (от **1.8** до **1.21.x** и **26.x**), гарантируя, что пакеты перевода версий работают с чистыми ванильными идентификаторами.

## 🎮 Автоматическое распределение режимов

Мод не требует настройки и работает полностью автоматически:

| Режим игры | Поведение |
|---|---|
| **Одиночная игра (Singleplayer)** | Изоляция **выключена**: все ваши блоки, мобы, крафты и предметы из всех модов работают в полном объёме |
| **Ванильный сервер (Vanilla / Paper / Purpur / Spigot / Realms)** | Изоляция **активна**: вы подключаетесь без конфликтов реестров и вылетов |
| **Сервер с установленными модами (Fabric)** | Изоляция **не мешает**: моды, присутствующие на сервере, работают и синхронизируются штатно |
| **Подключение через ViaFabricPlus (любые версии)** | Изоляция **активна**: трансляторы пакетов работают с эталонными ванильными таблицами |

## 📦 Сборка

```bash
gradlew build
```

Готовый файл: `build/libs/Modded2Vanilla-1.21.4-byMr712.jar`.

## 🚀 Установка

1. Установите **Fabric Loader** (0.16.0+) и **Fabric API** для 1.21.4.
2. Поместите `Modded2Vanilla-1.21.4-byMr712.jar` в папку `mods/`.
3. *(Опционально)* Установите **ViaFabricPlus**, если планируете подключаться к серверам других версий.
4. Запустите игру.
