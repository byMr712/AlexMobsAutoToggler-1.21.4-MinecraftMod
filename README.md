# Vanilla Recipe Isolator (Minecraft 1.21.4 Fabric)

Универсальный клиентский мод для **Minecraft 1.21.4 (Fabric)** — идеальный компаньон для **ViaFabricPlus** и ванильного мультиплеера. Обеспечивает полную изоляцию реестров модов при входе на любые серверы, предотвращая визуальные и сетевые конфликты.

---

## 🌟 Идеальная синергия с ViaFabricPlus

Если вы любите играть в одиночном мире с контентными модами (на новые блоки, еду, декорации, мобов и оружие), но также подключаетесь к серверам самых разных версий через **ViaFabricPlus** — этот мод создан для вас!

Обычно клиентские контент-моды загрязняют локальные реестры Minecraft, ломая сетевые трансляторы протоколов. **Vanilla Recipe Isolator** решает эту проблему раз и навсегда: вы можете держать в папке `mods` любые контент-паки и одновременно заходить через ViaFabricPlus на серверы любых версий (от **26.x** и **1.21.x** до **1.16**, **1.12** и **1.8**).

---

## 🛠️ Что решает Vanilla Recipe Isolator

Когда на клиенте установлены контент-моды (например, `tide`, `regs-more-foods`, `StrawBed`, `TotemCraft`, `Alex's Mobs` и др.), они регистрируют свои блоки, предметы и поля сущностей в общие реестры игры. При подключении к ванильным серверам и серверам через ViaFabricPlus это приводит к багам:

1. **Защита палитры блоков (`Block.STATE_IDS` / чанки)**:
   - Блоки модов смещают глобальную таблицу ID блоков. В результате переводчик протоколов ViaFabricPlus или ванильный сетевой стек отображают блоки некорректно (тростник превращается в аметист, сундуки в мод-блоки и т.д.).
   - **Vanilla Recipe Isolator** перехватывает запросы к `Block.STATE_IDS` и выдает строго эталонную ванильную карту ID 1.21.4.

2. **Нормализация ID предметов (`Item.byRawId`)**:
   - Гарантирует, что сетевые пакеты предметов всегда оперируют чистыми ванильными номерами предметов без сдвигов от модов.

3. **Защита сетевых метаданных существ (`DataTracker`)**:
   - Моды на сущностей (такие как `Alex's Mobs`) внедряют лишние поля в `LivingEntity`, что вызывает `IllegalStateException: Invalid entity data item type` при входе на мультиплеер.
   - **Vanilla Recipe Isolator** динамически выравнивает индексы полей и блокирует несовместимые сетевые обновления.

## 🎮 Как работает распределение режимов

| Режим игры | Поведение |
|---|---|
| **ViaFabricPlus (26.x, 1.21.x, 1.16, 1.12, 1.8 и др.)** | Изоляция **активна**: таблицы ID чистые, ViaFabricPlus работает идеально точно |
| **Ванильный мультиплеерный сервер** | Изоляция **активна**: исключены любые визуальные и сетевые конфликты |
| **Сервер Fabric со всеми вашими модами** | Изоляция синхронизируется через Fabric API |
| **Одиночная игра** | Изоляция **выключена**: все блоки, рецепты, предметы и мобы из модов работают на 100% |

Переключение происходит абсолютно автоматически — никаких конфигов и ручных действий.

## 📦 Сборка

```bash
gradlew build
```

Готовый файл: `build/libs/VanillaRecipeIsolator-1.21.4-byMr712.jar`.

## 🚀 Установка

1. Установите **Fabric Loader** (0.16.0+) и **Fabric API** для 1.21.4.
2. *(Рекомендуется)* Установите **ViaFabricPlus** для подключения к любым версиям серверов.
3. Поместите `VanillaRecipeIsolator-1.21.4-byMr712.jar` в папку `mods/`.
4. Запустите игру.
